# `compileWhile`

## Purpose

The `compileWhile` function compiles a `while` statement in the Quantum Language compiler. It generates bytecode representing the logic of a `while` loop, including condition evaluation and loop body execution. The primary goal is to ensure that the loop runs as long as the specified condition remains true.

## Parameters

- `s`: A reference to the `WhileStatement` object representing the `while` statement to be compiled.

## Return Value

This function does not explicitly return a value. Instead, it modifies the internal state of the compiler by appending bytecode instructions to the current chunk.

## How It Works

1. **Initialization**:
   - The function starts by recording the current position in the bytecode chunk where the loop begins using `int loopStart = static_cast<int>(chunk().code.size());`.
   - It then calls `beginLoop(loopStart)` to initialize any necessary metadata or state related to the loop.

2. **Condition Compilation**:
   - The condition expression of the `while` statement is compiled using `compileExpr(*s.condition);`. This results in bytecode that evaluates the condition.
   - After compiling the condition, an unconditional jump instruction (`Op::JUMP`) is emitted to determine whether the loop should continue. The target address of this jump is stored in `exitJump`.

3. **Loop Body Compilation**:
   - A new scope is started with `beginScope();` to isolate variables declared within the loop body from those outside.
   - The loop body node is compiled using `compileNode(*s.body);`, which recursively processes all nodes within the loop body.
   - Once the loop body is compiled, the scope is ended with `endScope(line);`.

4. **Continue Jumps Patching**:
   - The function iterates over all continue jumps recorded for the current loop using `for (size_t ci : loops_.back().continueJumps)`. Each continue jump is patched to point back to the beginning of the loop body.

5. **Loop Instruction Emission**:
   - The `emit(Op::LOOP, static_cast<int>(chunk().code.size()) - loopStart + 1, line);` instruction is emitted to create a loop structure. This instruction specifies the number of bytes to jump back when the loop continues.
   - The `patchJump(exitJump);` function is called to update the target address of the jump instruction stored in `exitJump`. If the condition evaluates to false, the loop will exit at this point.

6. **Post-Loop Cleanup**:
   - Finally, the function emits another `Op::POP` instruction to remove any values that might have been left on the stack after the loop.
   - The `endLoop()` function is called to conclude any loop-specific cleanup or finalization.

## Edge Cases

- **Empty Condition**: If the condition expression is empty or evaluates to a constant false, the loop will not execute at all. The bytecode generated will effectively skip the entire loop.
- **Nested Loops**: The function handles nested loops correctly by maintaining a stack of loop information (`loops_`). Each loop's start position, continue jumps, and exit jumps are managed separately.
- **Break Statements**: The `compileWhile` function interacts with break statements through the `loops_` stack. When a break statement is encountered, it updates the exit jump to point to the next instruction after the loop.

## Interactions with Other Components

- **Chunk Management**: The `compileWhile` function operates on the current bytecode chunk (`chunk()`) managed by the compiler. It appends new instructions to this chunk.
- **Scopes**: Scoping is handled by the `beginScope()` and `endScope()` functions. These manage variable lifetimes and visibility within the loop.
- **Loops Stack**: The `loops_` stack keeps track of loop-related data such as start positions, continue jumps, and exit jumps. This allows the function to handle multiple nested loops correctly.
- **Jump Instructions**: The function uses various jump operations (`Op::JUMP_IF_FALSE`, `Op::JUMP`) to control the flow of execution within the loop. These operations rely on the `emitJump` and `patchJump` functions to maintain correct addresses.

By following these steps, the `compileWhile` function ensures that the `while` loop is correctly represented in the generated bytecode, allowing the quantum program to execute as intended.
